# Giga Pet

CIT 384 Project 2: a simple Giga Pet game built with JavaScript and jQuery.

**Live site:** https://josejr04.github.io/comp484-project2jr/

## Features
- Treat, Play, Exercise, and Sleep buttons that change the pet's weight, happiness, and energy
- Values can never go below zero
- The pet comments after every button press
- jQuery methods used: `.css()` and `.fadeToggle()`
